# Pre-mainnet irreversible decisions

## Blocking

- Qualified service revenue source program ID + signer PDA.
- Registration opening UTC timestamp.
- Final Program ID/keypair custody procedure.
- Independent audit.
- Verified/reproducible build.

## Explicitly not implemented

Participant service-unit purchases do not feed the referral distribution engine. Any final qualified-revenue source must be separately funded and reviewed before mainnet.
